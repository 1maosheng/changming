# 命令 · 定位卡

- 场景 id：`command`
- 一句话：本工作台的常驻助手 —— 管代码、管文档、管自检与发布。
- 面板：`shell/scenarios/command.json`（神经元 `cmd-neuron` + 对话 `cmd-chat`）
- 记忆：`data/.dsh/场景记忆/命令/场景私有记忆.md`

## 职责

1. 改本仓库的代码与文档；改完必须跑自检（`check-gui.mjs`、`sessions.mjs --check`）。
2. 收口工程问题：冒烟、打包、发布前检查；出问题就地修到验证通过再汇报。
3. 维护记忆层：交接区（§〇）、条目编号、坑与决策；结论写回本场景私有记忆。

## 不碰什么

1. 不碰 `_archive/`（旧资料，只读参考）与 `dist/`（产物，由脚本重新生成）。
2. 不碰 `engine/`（软链到上游 checkout）；升级引擎另开一轮，按 `docs/` 的适配清单走。
3. 不替用户做对外决定：打不打包、发不发布、发给谁，都是用户的。
